# 上午还在写代码，下午工位就空了

早上七点爬起床，急急忙忙慌慌张，

11号线挤得慌，人贴人来墙贴墙，

扶手难抓脚难放，腿麻腰酸直晃荡，

高新中站一出场，拐个弯就到职场，

刷卡上楼腿发僵，工位一坐直犯痒，

打开VS Code亮堂堂，前端活儿堆成山岗，

样式没调心发慌，交互没成愁断肠，

bug缠我没商量，磨得脑壳直发烫，

泡杯白水润喉嗓，指尖敲得响当当，

JS CSS缠身上，忙得脚不沾地儿慌，

旁边同事凑身旁，唠起嗑来嗓门亮：

"产品改需求太嚣张，昨天定的今天忘，

纯属没事来瞎逛，脑子缺根弦儿晃！"

"前端内卷太疯狂，熬到深夜没奖赏，

像素对齐反复量，苦得只剩半条瓤！"

"通勤来回俩钟长，每天早起像打仗，

松岗到高新中一趟，堵得我快心发慌！"

俩人贫嘴没重样，唠完继续敲键盘响，

日子凑活混着强，谁也没放心里装，

一上午忙得慌慌张张，喝水都得挤空档，

好不容易bug搞定光，喘口气还没稳当，

组长消息来登场，让我去趟小会场，

心里咯噔一下凉，慌得手脚都发僵，

硬着头皮往前闯，怕露怯来怕出洋相，

打工人的体面要亮堂，遇事不怂不慌张！

进了会场心发慌，人事组长坐对向，

没有废话直开讲，字字句句像冰棒：

"架构调整要精简，前端岗位得缩减，

你被优化没悬念，赶紧交接别拖延！"

话术官方又冰凉，半点儿人情没商量，

我没吵来没闹嚷，也没emo没抓狂，

行情摆得明晃晃，裁员不算意外场，

早晚都是这一趟，坦然接受不逞强！

赔偿交接念一趟，我点头来没声响，

不委屈来不心伤，心里算盘打得响：

松岗民房要交粮，小猫等着我喂养，

前端手艺在身上，走到哪儿都能闯，

没啥慌来没啥丧，没啥纠结没啥怅！

走出会场心不慌，脚步稳稳不踉跄，

回到工位把物装，动作利落不慌张，

旧水杯磨得亮堂堂，薄荷糖来解闷慌，

前端笔记卷边样，记满坑来记满亮，

胡乱塞进帆布囊，关电脑时笑一场：

"总算能歇一歇场，不用熬到三更响，

不用被需求逼得慌，不用熬夜熬到黄！"

同事们都看身旁，没人多问没人讲，

不寒暄来不哄嚷，眼神交汇心明亮，

懂的都懂不拆穿，沉默就是体面样，

不用敷衍不用装，不用留恋不用强，

打工人的默契强，各自藏愁不张扬！

不道别来不逞强，背上背包就离场，

不拖泥带来不磨洋，走出办公心敞亮，

按下电梯往下降，直达一楼不彷徨，

推开大门风清扬，居然是甜不呛嗓，

没有压抑没有怅，一身轻松心花放，

所有疲惫所有慌，瞬间消散没影踪！

快步奔向地铁站场，人来人往忙又忙，

都是打工奔波郎，脸上疲惫藏心房，

混在人群不张扬，不落寞来不心凉，

反而自在又敞亮，不用赶工不用慌，

不用调样式反复量，不用熬夜到天亮，

不用挤夜车困得慌，不用点头快睡香！

上了11号线场，人挤人来没座享，

扶着扶手晃呀晃，耳机一戴隔尘壤，

不沉沦来不心伤，心里自有好主张，

裁员不是终点场，是新的起点新启航，

不用困在格子房，不用将就不顺畅，

不用看脸不用装，不用受气不用扛，

总有更好的缘分降，总有更宽的门敞亮！

裁员本是双刃剑，两面都有好与伤，

一面空档没饭享，一面选择更坦荡，

一面迷茫心发慌，一面光亮在前向，

不遗憾来不慌张，不否定来不彷徨，

打工人的底气强，不在固定岗和场，

手里本事够硬邦，心里底气够狂放！

颠簸一时到松岗，走出地铁往巷闯，

民房小巷烟火旺，邻居炒菜香又香，

不比写字楼冰又凉，多了人间真模样，

不比格子间闷又慌，多了自在心舒畅，

不戴面具不装腔，做回自己坦荡荡！

掏出钥匙把门敞，小猫扑来心花放，

蹭我裤腿软又香，喵呜喵呜叫得响，

知道我早回身旁，格外黏人又热肠，

蹲下来把它摸赏，软乎乎的暖心房，

所有烦恼所有慌，全被治愈没余伤，

打工人的小温柔，都在这细碎时光！

民房不大却敞亮，没有压抑没有绑，

没有KPI压心房，只有小猫呼噜响，

卸下伪装坦荡荡，不用逞强不用装，

上午还在敲代码忙，晕头转向没主张，

下午工位就空荡，没了束缚心敞亮，

新的方向新启航，不慌不忙不卑亢！

以前总怕失业慌，怕不稳定没保障，

怕日子没奔头望，怕熬不到天亮光，

现在才懂这规章，停顿不是退后方，

不是沉沦不是伤，是为前行更坦荡，

告别不是遗憾场，不是伤痕不是凉，

是为遇见好风光，遇见对的好儿郎！

打工人的路漫长，起起落落很正常，

跌跌撞撞又何妨，越走越稳越敞亮，

前端手艺没忘光，努力劲头没躲藏，

小猫陪伴暖心房，有暖可寻有希望，

哪怕暂时空档档，哪怕偶尔心发慌，

从容不迫向前闯，不负自己不负光，

起起落落是寻常，跌跌撞撞也能强，

越闯越顺越风光，日子越过越晴朗！
