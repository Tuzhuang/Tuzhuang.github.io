# 怎样搭建一个简易的 STRUTS2 项目呢？

下面就是一个简单易懂的 STRUTS2 项目简易搭建过程！！！

本文详细介绍了如何从零开始搭建一个简单的 Struts2 项目，包括下载源码 jar 包、配置 MyEclipse、添加必要 jar 包、编写 action 类及配置 web.xml 等步骤。

## 步骤 1：下载源码 jar 包

先去 Struts2 官网下载源码 jar 包，网址：[https://struts.apache.org/](https://struts.apache.org/)

## 步骤 2：选择版本

进入页面后，点击 `download` 按钮，跳转到下载页面，选择 Full Distribution 版本的 struts2，如：`struts-2.3.24-all.zip`。

## 步骤 3：解压

解压 `struts-2.3.24-all.zip` 压缩包。

## 步骤 4：创建 Web 项目

打开 MyEclipse 开发程序，新建一个 web 项目，输入项目名字（这里起的是 `Struts2HelloWorld`，名字随便起），配置一下 Target runtime，然后点击 finish 即可。

最后在 WebContent 下面的 WEB-INF 下的 lib 中加入如下 9 个 jar 包（这 9 个 jar 包在你下载的 struts2.zip 里面的 lib 文件里面）：

- `commons-fileupload-x.x.x.jar`
- `commons-io-x.x.x.jar`
- `commons-lang3-x.x.jar`
- `freemarker-x.x.x.jar`
- `javassist-x.x.x.GA.jar`
- `ognl-x.x.x.jar`
- `struts2-core-x.x.x.jar`
- `xwork-core-x.x.x.jar`
- （如使用其他插件可能还需额外依赖）

## 步骤 5：编写 Action

写一个 action，action 其实就是一个 java 类：

```java
package com.hnpi.action;

import com.opensymphony.xwork2.ActionSupport;

public class HelloWorldAction extends ActionSupport {
    @Override
    public String execute() throws Exception {
        return "success";
    }
}
```

## 步骤 6：配置 web.xml

将 `struts2-blank/WEB-INF/里面的 web.xml` 文件复制，替换原本 web 项目里面的 web.xml 文件，或者直接在 web 项目的 web.xml 里面添加如下代码：

```xml
<filter>
    <filter-name>struts2</filter-name>
    <filter-class>
        org.apache.struts2.dispatcher.ng.filter.StrutsPrepareAndExecuteFilter
    </filter-class>
</filter>

<filter-mapping>
    <filter-name>struts2</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>
```

## 步骤 7：完成

出现以下提示就说明 struts2 项目搭建成功了！

然后搭建完成！！！
