# 使用ELEMENTUI的NAV-MENU组件，把默认的ICON图标替换成图片文件之后，图片不显示

本文讲述了如何在 Element UI 的 nav-menu 组件中将默认图标替换为图片，并解决动态路径转换为 Base64 的问题。通过 `require` 包裹动态路径，解决了 Vue 动态绑定图片 src 的困扰。

## 直接使用 IMG 标签生成，但是报错

当我想把 menu 组件默认的 icon 图标替换成图片的时候，直接设置一个 img 标签是可以的，路径直接写死了。但是因为是要循环，所以就想着用循环的路径，但是在页面上生成的时候就自动转成了 base64 格式的路径，但是我循环出来的路径就没有改变，导致页面上并没有显示出来图片。

第一个是直接写死的路径，在浏览器中就解析成了 base64 格式的，但是第二个 img 标签里面的路径是循环出来的就没有展示出来，这个问题头皮发麻，在网上百度了很多 nav-menu 关键词的帖子都没有找到更好的解决办法……

## 问题解决

绞尽脑汁想了一个小时还是没想出来，后来求助了一位前端大哥，把问题描述清楚之后，大哥二话不说告诉我解决办法，就是在路径外面用 `require` 包裹起来，他跟我说这个就是 vue 动态绑定图片路径的问题，用 `require` 包裹起来就没问题了。我尝试了一下，还是报错，语法错误，然后修正后，完美解决问题。

这时候，问题已经解决，竟然只是动态绑定图片 src 的问题，问题解决，大功告成，希望可以帮助到你。

```html
<img class="iconImg" :src="require('../../assets/images/' + item.icon + '.png')" alt="">
```

直接复制就行。
