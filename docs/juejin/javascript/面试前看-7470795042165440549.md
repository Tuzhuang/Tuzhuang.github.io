# 1.什么是异步任务？

代码在执行过程中，遇到的一些无法立即执行的任务就是异步任务。

# 2.什么是事件循环？

事件循环又叫做消息循环，是浏览器渲染主线程的工作方式。 事件循环可以分为主线程任务和微任务、延时任务以及交互任务，主线程任务优先执行的是代码从上到下的同步任务，微任务包括promise，延时任务就是计时器相关代码，交互任务就是用户的点击等其他操作，任务执行顺序是先执行主线程任务，然后执行微任务，接下来是交互任务，如果没有交互任务的话才执行延时任务。
