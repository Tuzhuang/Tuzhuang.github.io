# 解决ELEMENTUI表格边框错位问题

本文讲述了如何修复 Element UI 表格在滚动时边框错位的问题，通过设置 `overflow: hidden` 属性解决了滚动条外露导致的不雅观。作者分享了两种方法，最终选择了直接修改 `.el-table__body` 的样式以实现优雅显示。

当 ELEMENTUI 中的表格出现滚动条，拖拽的时候出现边框样式错位了怎么办，别急，让我来告诉你。

今天下午开开心心的写代码的时候突然发现我在饿了么中使用的表格组件，当我把滚动条拖到最右边的时候，竟然出现了样式错位，这可把我难到了，赶紧去百度，但是百度上常用的解决办法就是在全局文件中写一段样式，如下：

```css
body .el-table th.gutter {
  display: table-cell !important;
}

body .el-table colgroup.gutter {
  display: table-cell !important;
}
```

但是，经过尝试之后，在我的项目中并没有生效，可能在你们的项目中是可以的，万一呢，于是我又换一种方式，终于找到了一个解决的办法就是，简单粗暴，直接设置超出隐藏：

```css
.el-table__body {
  overflow: hidden !important;
}
```

经过一番小操作，完美解决问题。修改之前的可以看到，完全驴头不对马嘴，看上去简直强迫症想自杀，加上样式之后非常的优雅。好了，到这就完全结束了，大功告成！
