# 在深圳，普通的程序员工资怎么样？

## 回答

现在作为一个程序员，在大学之前以及上大学的时候，还不明白程序员到底是什么，只知道我的专业是计算机专业的，后面每天上课都是在敲代码敲敲敲的，但是还是不会，照着模板写一遍又一遍的，等到大学毕业的时候，那时候感觉完全不明白在学校学习了什么，出来找工作也不知道干什么，后来听一个哥哥说，要去培训机构培训一下，然后再找工作会比较好找一点吧，于是就去他推荐的一家培训机构。

那天刚去培训机构的时候，招生老师跟我介绍计算机程序员是分很多种的，有前端，有后端，还有测试ui什么的，当时我一脸懵逼，因为这些词在我的大学时光里是没有听过的，第一次听，我也不知道学哪个，那个招生老师跟我讲，现在前端是风口，学好了，猪都能飞起来（白眼 - -），然后我就报名了。当时学费差不多要两万（我19年年初报名的），然后就进入了基础班开始学习，因为我报完名的时候那时候还没有排班，我要等两周左右才有新的班级开班，当时那个招生老师就给我了一些基础班的视频给我看，我回家看了几天的视频，当时觉得，前端还是蛮有意思的嘛，画画页面，真的挺好的。

过了不久，就开新班了，我就去安排上课去了，刚开始那段时间，因为基础班的视频，我在家里面也看了不少，然后我学的其实还蛮轻松的，然后到后面学了什么js，上大学的课程我已经完全忘记了，我学js的时候差点给我学窒息，当时老师教了一个用浏览器的alert框实现的一个计算器的功能，这块功能没把我写死，我照着老师的抄了五遍可是还是没有理解，当时真的想放弃了，最后还是咬咬牙坚持下来的，但是感觉学的都七七八八的，心里没底。

到了毕业的时候了，同学们都去找工作了，我也不例外，投了投简历，因为我的简历是大专学历，然后又是刚毕业，刚开始的时候找我的人并不多，基本都没什么公司吧，当时我记得我面了一个在车公庙的公司，那个人面试我的时候问了我的好多问题，但是我都没有回答出来，那个大哥人很好，跟我说，像深圳程序员的话大部分也就集中在这一块，好好学习一下再找工作，当时我觉得我的头好沉，都抬不起来，我当时找工作的时候工资要的是8k，我出门之后跟我朋友说，我说真的好难啊，要不我们直接找一个实习的工作吧，管他多少钱，只要能活下去就行吧，然后后面又继续投简历，把简历的薪资稍微改低了一点，之后又收到了一个面试，是在宝安区西乡那边，我那天面试的时候出奇的顺利，因为是一家初创公司，公司老板跟我聊天的时候给我泡了一杯茶，边喝茶边跟我聊天，给我拿了好多公司的资质给我看，没有跟我聊技术，我跟老板大概聊了四十多分钟吧，其实，也没有聊啥，就是老板说啥，我就嗯嗯，这家的薪资我要了7k，回家之后我就准备了一下，过了两天就来上班了。

上班的第一天，上午就是把电脑上面该下载的东西下载一下，装一装环境什么的，然后中午的时候，老板我们两个人一起下楼吃饭，老板请我吃了一份盖浇饭，下午的时候，他就开车带我去了另外一家公司，那个公司的ui跟我讲了讲要做啥，做的效果是啥的，我听得懵懵懂懂的，就又跟老板回去了，回去之后，已经到了快下班的时间，老板就说走吧，不用加班了，第一天的工作就做了这些，后面又第二天的时候，因为之前约了有面试，然后老板就随便面了一下，问了好多技术问题，结果那个人没有回答出来，就这样不了了之了，这样想想，当时我没有面试技术还是挺幸运的，大概做了四五天吧，我的技术实在是太菜了，老板都看不下去了，我自己也看不下去了，做的东西可慢可慢了，老板就又叫我喝茶，给我倒了一杯茶，然后就跟我说，我的技术可能不太好，但是这几天的工资还是有的，然后我就回家了，第二天过来签了离职证明，我就走了。

然后继续找工作，发现工作找不到了，就在家自学之前的知识，学了一个月左右吧，当时的招生老师跟我讲说只要再交几百块钱就可以重读了，再学一遍，当时我在想是自己学习还是自学呢，后面考虑了一下，然后交了几百块钱就去重读了，这次重读的时候我特别认真，然后感觉知识也学到了很多，至少比第一次强太多了，当初折磨我的那个计算器功能，现在我也能很熟练的写下来了，就这样又学习了半年左右，又到了找工作的时候，但是那时候刚好又碰到了疫情，我没有办法，就打电话面试，有的地方是线下面试，有的就视频啊，或者腾讯会议啥的，就这样面了几个之后，找到了两家公司，一家公司就是中科软是外包到恒大集团的，还有一个是一个小公司，但是离我家实在太远了，我就去了中科软这家公司，当时的薪资也没有要太多，因为是电话面试的，我要的是9k，但是他说因为你是大专学历，我们只能给到你8500（踏马的，后来想想，这是什么奇葩理由）但是当时的我还是去了，因为经历了第一次上班做不出来，其实这次虽然学的还不错，但是还是不太敢，然后就去了。

第一天刚到公司的时候，我在外面没有门禁进不来，然后我的项目经理出来带我进去了，进去之后发现，真的是好家伙，大家都穿的正装，白衬衫，西装裤子小皮鞋，我一个人穿个牛仔裤就来了，然后项目经理问我怎么穿这身就来了，我淦，我不穿这个穿哪个，给我领到了工位上，给我了一个笔记本，然后就又是正常的工作，装装环境啥的，然后第一天晚上就加班到了8点多，当时也没啥事干，就给我了一个项目让我看，但是其实我是想走，但是大家一个人都没有走，当时项目组的人并不多，就只有几个吧，然后第二天，来了两个新同事，我们三个人关系还不错，就当时觉得公司还行吧，至少有同事在，相处的还行，然后过着过着，项目组来的新同事越来越多，但是人都挺好的，都是跟我差不多大的同事，所以相处起来还不错，当时我对工资也挺满意的，没有想太多，后来跟我当时一起培训的朋友聊天吃饭的时候才发现他们的工资真的好高，但是当时我心里面也没有啥，因为我觉得我现在在的公司除了领导，同事之间都还是挺不错的，然后我就一直在这待了有半年多吧，因为工作的原因，我有些同事离职了，有些同事被调到了其他的项目组，福田那边，我还在这个项目组，留下来之后，来了一批新同事，从四面八方来的，年龄也比我大，我丢，我也没啥可聊的了，然后就提了离职，这时候搞笑的来了，之前我跟项目经理说可以提前转正吗？他就说我犯了错误，让我写一个什么类似于检讨书似的，为什么会犯错，犯错因为啥，以后怎么做，好家伙，我当时没写，我也没转正，然后项目组几乎所有人都提前转正了除了我，然后当我准备离职的时候还没有提出来的时候，项目经理主动找我，要给我涨工资，大概他的意思只能涨1000左右吧，我说我要到1w，他说你觉得1w的工资要达到一个什么样的水平，真恶心，又说这种话，然后我就直接说我年后要离职，因为当似乎块21年春节了嘛，他挽留了一波，说你再考虑考虑，公司有调薪机会，我第一个就想到你了，真的是老太太进被窝，给爷整笑了。

剩下的下次再更~~

  

来了，后面过完年之后就离职了，然后回老家了一个多月，大概是4月中的时候开始找工作的吧，然后就是面试面试，大概面了一周然后就找到了工作，是一个小公司，花了300块买了一个假学历，然后boss上面很多公司疯狂邀请去面试，因为我是可以接受外包的，有些人说什么外包是一辈子的污点啊啥的，其实没有这么严重，上班本来就是为了钱，有钱啥活干不了嘛，反正我是这么觉得，有的人可能有更高的追求吧，我就是一个普普通通的打工仔，有钱赚就行了，我也没有想过做前端界的大佬，然后我面试的时候，我跟面试官吹我说我上家公司的薪资是10k，现在想要12k，然后面试的过程怎么说呢，周一的时候面试的还不错，跟面试官聊了挺长时间的，周二的话就中规中矩吧，周三那天我约了5个面试，上午两家，下午三家，上午的两家，一个是公司一个前端都没有就招我一个进去做一个可视化的后台管理系统，我看了看，没去，直接说我不考虑，然后就没面了，另外一个是我去的时候，公司的员工说经理出去打疫苗了，我看那个工作环境和人数就三四个人，也是人太少了，然后就没面了，然后就去下午面试的附近去麦当劳吃了个饭，里面休息了一会，就去面试了，下午的第一家面试，我进去之后先做了一份笔试题，最恐惧笔试题了，因为技术也不高，所以，做题的效果可想而知，做的七七八八的，过了一会面试官进来了，很胖很壮，问了我一些问题，面试官挺好的，问我没有回答出来的问题还给我讲解一下，虽然我还是没听懂，但还是不错，所以，我就凉凉了，然后踩上单车去下一家，是在科学园那边，找了好久才找到那栋楼，进去的时候，面试官也是给我了一套笔试题（我真晕了，下次我一定不面有笔试题的了），然后他看着我做的，第一个是给一段代码里面找bug，我找出来了，然后有两个逻辑题，问我5点25分的时候时钟的时针和分针的夹角是多少，我愣了，我以为是脑筋急转弯，没想到他说这是小学的逻辑题，我想了好久想出来了，他若有所思的点点头，接着第二个逻辑题，我是真的不会的，是二元一次方程式，现在早忘了啊，所以，简单问了一下项目，这家也凉凉，我又接着去最后一家，最后一家好像是在车公庙那边，我去的时候人家都要下班了，只有面试官还在等我，我表示很抱歉，面试官跟我说，公司不加班，但是只招一个前端，然后没有ui，总的来说，就是前端要把ui的活也给揽了，独立开发我肯定是接受不了的，然后我随便聊了几句就下楼了，下楼之后正好是下班高峰期，我也不想挤地铁了，就在楼下坐着抽烟，想着今天真的不顺，面了这么多，没有一家合适的，然后坐着坐着，就开始有点难受了，想着找工作咋就这么难呢，买了瓶康师傅茉莉花蜜茶，又点上了一根烟，望着天空........

紧接着周四我没有去面试，我在家睡了一个懒觉，昨天的事情也忘的一干二净了，下午在家玩玩手机，看看电视，晚上把周五要面试的公司排了一下就睡觉去了，周四的时间就过去了，周五起了个大早，买了两个包子一杯豆浆，吃完就去面试了，上午来的第一家公司是在福田，出地铁站还走了好久，面试官是一个年轻小伙，公司里面我没有看到别的同事，就看到他和几个女生在聊天，我觉得这里并不是办公地点，然后他就说了，他说他们是外包公司，外包公司主要是做小程序的，所以问我会不会小程序，外包的那家公司放假从来不用补班，还是挺有吸引力的，但是我说我不会小程序，但是可以学习，他说目前他们那边想找一个熟练小程序开发的人，那好吧，我不配，他把简历还给我我就下楼走了，上午的面试就这一家，下午有两家，第一家面试的时候好家伙，是我面试轮数最多的一次，先是人事跟我面了下工作经历啥的，然后面完之后又让技术来面试我，最后又让架构师来面试我，面试了老半天，最后说回去等下通知，最后也没有要我，最后一家我去了南山那边的一家公司，公司不大，面试我的是一个前端，然后就聊了下项目和技术，觉得还不错，出门的时候我挺高兴的，因为我也感觉面试的不错，正往地铁站走，电话响了，是周一的那家公司跟我说面试通过了，问我什么时候有时间来入职，我说我考虑下吧，下周一之前给你答复，然后就开心的回家了，回家之后大概是周六的时候吧，周五面试的那家也跟我说面试通过了，后面我鬼使神差的选择了第一家，事实证明我选错了，去入职那天刚到公司，我去了之后说我是来入职的，然后一个前端老大就让我先坐着，然后过了一会给我安排了一个位置，跟我说插网线，然后上面有一个入职文档，让我办理入职，可是我找不到办入职的那个人，只在第一天录了一个打卡机的指纹，第一天没什么事，我下午临下班的时候问我旁边的测试几点下班，他说你今天第一天来，最好不要走太早，我tm，我第一天没别的事，在这呆着干嘛，然后没办法，我就待到了7点，他们还在加班，我就直接走了，回家的路上想，要不是工资高，我早就不伺候你了，第二天上班的时候，领导给我讲了需求（没听懂），然后跟我讲这个项目是react的，让我学习一下尽快上手，我一下子惊了，我说我面试的是vue的啊，不是react的，他说，嗯是的，你先把这个做完后面再做vue的项目吧，我看着那个react的项目头皮发麻，受不了几天我离职了，然后跟我之前面试成功那个说，现在还招人吗，招的话就去，不招的话就算了，刚好那边还空缺一个职位，我就在五一之后就入职了，入职之后，感觉也还好，同事还行，就是不爱说话，上班跟午休一样，一点声音都没有，一天在公司说不了十句话，真的就很郁闷，不过这家公司挺好的，中午就休息一个小时，但是6点是准时下班的，如果没有别的事情的话，大家都是6点左右就下班了，项目上线的时候会加班到比较晚，老板也会点一些麦当劳什么的，所以总体也还好，但我今年找工作的时候就在想要找一个环境好点的，这个公司上班时间中午休息一个小时是真的太少了，然后同事间都不讲话的，真的是敲代码的机器，然后我待了快三个月，转正前几天我就离职了，对了，这家的薪资和之前那个是一样的。
